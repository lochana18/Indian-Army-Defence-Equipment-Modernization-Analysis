# 🛡️ Indian Army Defence Equipment & Modernization Analysis

## 📌 About the Project

This is a Streamlit-based data analysis project created to study and visualize information related to Indian Army defence equipment and modernization.

The project uses Python, Pandas and Plotly to analyze the available defence equipment data and present the results through interactive charts and a simple dashboard.

The main aim of this project is to understand the data easily through visualization instead of looking at only raw tables.

## 🎯 Project Objectives

* Analyze Indian Army defence equipment data
* Understand equipment categories and their distribution
* Compare different equipment based on available data
* Study modernization-related information
* Create interactive charts and visualizations
* Present the analysis through a user-friendly Streamlit dashboard

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* Excel Dataset

## 📊 Project Features

* Interactive Streamlit dashboard
* Data filtering and analysis
* Different types of charts
* Equipment-wise analysis

* Easy-to-understand visualizations
* Simple and user-friendly interface

## ▶️ How to Run the Project

First install the required Python libraries:

```bash
pip install streamlit pandas plotly openpyxl
```

Then run the Streamlit application:

```bash
streamlit run project.py
```

The project will open in the browser.

## 📈 Output

The application displays the defence equipment analysis using interactive charts, tables and visualizations.

It helps users understand the available data in a simple and visual way.
